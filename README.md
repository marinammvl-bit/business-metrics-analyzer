# Business Metrics Analyzer

Практическое задание №1 по дисциплине: «Проектирование и разработка бизнес-ориентированного программного обеспечения»

## Бизнес-задача

Расчёт и визуализация ключевых показателей эффективности (KPI) предприятия.

## Стек

- Python 3.10+
- pandas
- matplotlib

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate   # или .venv\Scripts\activate для Windows
pip install -r requirements.txt
python main.py
```
## Пример бизнес-задачи

Компания хочет понять, в какие месяцы выручка растёт, а в какие падает,
и сравнить показатели с планом. Для этого нужно:

1. Собрать данные о выручке по месяцам.
2. Рассчитать среднее значение и отклонение от плана.
3. Построить график динамики.

## Планируемые метрики

- Выручка по месяцам — суммарная выручка за каждый месяц.
- Средняя выручка — среднее арифметическое по всем месяцам.
- Отклонение от плана — разница между фактом и планом в процентах.
- Темп роста — отношение текущего месяца к предыдущему.
